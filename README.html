🌿 Au Fond du Jardin — Station Agro-Météo Autonome

GNU GPLv3   Auteur : Bruno Romero (Curl est ton ami) — 2026

Application web dynamique, légère et sécurisée dédiée au suivi agronomique des vergers et potagers (relief, GDD, précipitations cumulées, IQA et vigilances gel/canicule).

📱 Guide d'utilisation pour les compagnons (Mobile)

Pour tes compagnons, l'utilisation ne nécessite aucun compte, aucun serveur local et aucune installation d'application.

  1. Ouvrir le lien : Cliquer sur le lien web reçu par SMS/WhatsApp (ex: https://ton-pseudo.github.io/au-fond-du-jardin).
  2. Régler son terrain : Appuyer sur le bouton ⚙️ Réglages Mon Terrain en haut de page.
  3. Saisir ses coordonnées : Renseigner le Nom du site, la Latitude, la Longitude et le Code INSEE de la commune.
  4. Enregistrer : Cliquer sur « Enregistrer & Mettre à jour ». Les coordonnées sont conservées dans la mémoire locale (localStorage) de leur propre téléphone.
  5. Raccourci écran d'accueil : Dans le menu du navigateur mobile (Chrome/Safari), choisir « Ajouter à l'écran d'accueil » pour y accéder comme une vraie application.

🛠️ Déploiement sur GitHub Pages (Pour le créateur)

1 Générer le fichier HTML

Exécuter le script Python pour créer le fichier index.html autonome :

python3 au_fond_du_jardin.py

2 Créer le dépôt GitHub

  1. Se connecter sur github.com et créer un nouveau dépôt public nommé au-fond-du-jardin.
  2. Déposer les fichiers index.html, au_fond_du_jardin.py et README.html dans la branche principale (main).

3 Activer GitHub Pages

  1. Sur GitHub, aller dans l'onglet Settings > Pages (menu de gauche).
  2. Dans Build and deployment > Source, sélectionner Deploy from a branch.
  3. Choisir la branche main et le dossier / (root), puis cliquer sur Save.
  4. Après 1 à 2 minutes, GitHub fournit l'adresse web publique du projet.
